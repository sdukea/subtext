# Source Register

Merged register of every source cited in the SubText product-discovery research. Each workstream's table is reproduced in full below; the per-workstream originals remain in `sources/`.

**Columns:** # · Source title · Publisher/author · URL · Publication date · Date accessed · Research category · Key findings · Conclusions supported · Reliability assessment.

**Reliability scale:** High = primary source (official docs, statute, peer-reviewed paper, large-panel data) read directly; Medium = credible secondary source, preprint, or vendor data with stated method; Low = blog, untraced statistic, vendor marketing, or snippet-only. `[snippet only]` = the page itself was not read; claims resting on it are flagged in the reports.

**Access dates:** sources were accessed 2026-11-13 unless a row says otherwise; coordinator re-verifications on 2026-11-18 are noted in `RESEARCH_LOG.md`.

**Cross-reference:** reports cite sources inline by URL and by ID (`[WS1-12]`, `[RT-3]`, …).
